- 위치: `temp/saving-share-v4-chat/` (원본 `temp/saving-share-v4 (2)/`는 손대지 않음)
- 빌드 결과: `web/index.html` (서버용) · `out/preview/index.html` (서버 없는 미리보기)

## 1. 지킨 디자인 규칙

사용자 요구를 그대로 옮긴 것과, 그걸 어떻게 지켰는지.

- **토스처럼 필요한 것만 · 한 번에 하나**
  - 챗봇 버튼을 화면에 늘 띄우지 않는다. 필요한 순간, 그 자리에서만 권한다(2장).
  - 흐름 중간에 묻지 않는다. "이 기기에 저장할까요?"는 없앴고, 찾은 건물은 이 기기에만 알아서 기억한다(서버로 안 보냄). 다음 방문 때 주소 칸 아래 "최근" 한 줄 + ×로 지운다.
  - 주소 찾기는 칸 하나. 🎤는 칸 안 아이콘, 따로 누르는 찾기 단추 없음. 입력을 멈추면 바로 아래 결과 한 줄 → 누르면 끝.
- **회색 설명은 (i)·▼ 뒤로**
  - 답의 유의사항(notices)은 꼬리표 옆 (i) 안에.
  - 기저선 제목 "금액을 확정하지 않고 시뮬레이션·범위로만 제시합니다"(‘그래서 뭐?’ 문장) → 제목은 사실만 "예측 정확도가 기준보다 낮아요", 결과는 꼬리표 옆 (i) 안으로.
  - 합의 카드 속 설명 문장(note)은 위 답 문장과 같은 말이라 뺐다.
- **AI 설명은 처음엔 닫힘** — 정산 화면 AI 설명은 접혀 있고, 달을 누르거나 ▾를 눌러야 열린다.
- **토스식 진행 화면 · 빨라도 최소 시간**
  - "흐르는 점": 점은 제자리, 밝기만 왼쪽→오른쪽으로 번진다(실제로 움직이지 않는데 건너가는 느낌). 단계는 차례로 체크.
  - 챗봇 분석(합의·분석·신뢰) 최소 4초 · 건물 찾기 2.6초 · 되묻기 1.1초 → 그 뒤 답이 부드럽게 올라온다.
  - 정산 AI 설명: 처음 여는 달은 4초 살펴보기 화면.
  - 처음 화면 → 앱: 실제로 불러오는 4가지(대상 판정·사용량·기저선·분배)가 응답을 받아야 하나씩 체크(최소 3.2초, 최대 6.5초).
  - 단추 로딩은 회전 원 대신 점 세 개.
- **회수선 자석** — 분배 슬라이더가 회수선 ±2.5%p 안에 오면 회수선(예: 49.5%)에 딱 붙고 선이 초록·✓로 바뀐다. 화살표 키는 5%씩, 사이에 회수선이 있으면 한 번 멈춤. 저장된 시연 데이터는 5% 칸만 있어 회수선 바로 위 칸에 붙는다.
- **다크 기본 · 초록** — 처음 그릴 때부터 다크(번쩍임 없음), 밝은 화면 전환: 처음 화면 위 · PC 오른쪽 레일 · 모바일 전체 단계 메뉴. 강조색 #0F9D58(흰 글씨 대비 3.51 — 토스 파랑 3.65 와 비슷). 토큰만 바꿨으니 다른 초록을 쓰려면 `styles.css` 맨 위 `--primary*` 만 고치면 된다.
- **움직임은 과하지 않게** — 화면이 바뀔 때·답이 나올 때·숫자가 나올 때만. 기기 '움직임 줄이기'면 멈추고 대기도 짧아진다.
- **모바일은 보고 있는 화면에서 바로 · PC는 통일성**
  - 모바일: 대화는 기존 아래 시트(88%), 답 카드에서 바로 [이 조건으로 보기] → 분배 화면으로 옮기고 "조건을 바꿨어요 · 되돌리기".
  - PC: 대화는 기존 오른쪽 칸(AI 설명·내 건물과 같은 자리, 400px). 특약 복사도 PC는 오른쪽 칸(스크롤 없이 보이게).

## 2. 챗봇이 나타나는 자리 (늘 떠 있지 않음)

- 처음 화면: 시작 단추 아래 작은 글자 단추 **✦ 말로 할래요** → 대화 화면(필수 안내 두 가지를 꼬리표로 보여줌)
- **(i) 설명 안**: 설명 아래 한 줄 "✦ … 물어보기" — 분배(회수 기간·임차인 절감·회수에 필요한 몫), 기저선 지표·기준 미달, 정산 금액
- **헤맬 때만 초록 말풍선** (닫으면 이 탭에서 다시 안 나옴)
  - 분배 슬라이더를 25초 안에 4번 넘게 되풀이 → "원하는 회수 기간이 있나요?"
  - 코드로 찾기에서 빈칸·못 찾음 → "코드를 몰라도 괜찮아요 [주소로 찾기] [AI에게 말하기]"
- **배경 없는 한 줄 링크**: 계산 근거 ▼ 안, 기저선 기준 미달, 정산 '확인 중' 달의 AI 설명 안, 특약 오른쪽 칸, 공사비·기간 시트 "말로 정할래요"
- 모바일 전체 단계 메뉴 맨 위 한 줄 · PC AI 설명 칸 맨 위 한 줄
- PC 오른쪽 레일 "세이빙 AI" 는 **대화를 한 번 시작한 뒤에만** 생긴다

## 3. 대화창

- 위: 세이빙 AI · [건물주 | 세입자] (바꾸면 문장만 바뀌고 숫자는 그대로)
- 답: 꼬리표(🤝·🏢·🔎·🛡) + 시뮬레이션/가상 데이터 꼬리표 + (i) 유의사항 → 문장 → 카드 → 근거 칩(누르면 그 단계로)
  - 🤝 합의: 두 장 나란히(기본 추정·안전하게), 줄마다 기본 추정일 때·낮을 때, 목표 못 맞추면 빨간 "목표 초과". [특약 만들기] [이 조건으로 보기]. 회수 불가면 대안 두 개 → 그 조건으로 다시 계산
  - 🏢 건물: 후보 + [아니에요][맞아요] → 열면 기기에 기억 · 처음 화면에선 [이 건물로 시작하기]
  - 🔎 분석: 비교 해가 바뀌면 노란 띠, 두 달 실측, 기온 영향·기온 외 요인, 현장 확인 목록 (근거는 카드에 있으니 칩 대신 "기저선 화면에서 보기")
  - 🛡 신뢰: 정산 상태 + 예측 오차·설명력 충족/미달
- 아래: 추천 질문 칩 3개(서버 칩 우선, 없으면 단계별) → [🎤][입력][보내기]
- 개인정보 가림(요구서 4-5 정규식) 후 전송, 처음 한 번 "개인정보는 보내지 않았어요"
- "내 건물 주소가 뭐였지?" → 서버 안 부르고 기기에서 답
- 서버가 꺼지면 입력 막힘 · 칩만 · 저장본에 없으면 "서버 연결 시 대화할 수 있어요"(오류가 아닌 안내로)
- 정산 분기: 모바일은 칩 대신 한 줄 단추(지금 분기 ▾) → 아래 시트에서 고름 (옆으로 밀지 않게). PC는 칩 그대로
- 🎤 B 방식(브라우저 Web Speech): 안 되는 브라우저·http 에선 숨김, 최대 10초, 자동 전송 안 함. 처음 한 번 요구서 고지문을 **막지 않고 알림으로** 보여줌

## 4. 서버와의 약속 (`/api/assist`)

요청 `context` 에 화면 값을 더 보낸다 (요청서 C-2 제안):

```json
{ "message": "…", "context": { "step": "alloc", "bld_id": 1, "viewer": "owner",
  "invest_won": 50000000, "owner_ratio": 0.7, "target_years": 10, "quarter": "2026-1",
  "last": { "intent": "mediate", "invest_won": 50000000, "target_years": 8 } } }
```

응답에서 화면이 쓰는 것 — 요구서 3장 + 아래 제안:
- `chips` 는 문자열 · `{ "label", "message" }`(보냄) · `{ "label", "fill" }`(보내지 않고 입력창에 넣음)
- `actions`: `set_alloc`(버튼을 눌러야 실행) · `set_viewer`(`{"type":"set_viewer","viewer":"tenant"}`, 받자마자 반영)
- `source: "external_ai"` 면 "외부 AI 사용" 표시
- 숫자는 화면에서 계산하지 않음 (천 단위 쉼표와 % 표시만)

`?mock=1` 이면 `src/core/mockAssist.js` 가 요구서 3장 예시 값을 그대로 돌려준다(낱말로 대충 고름, 시연 1~9용).

고친 파일
- `App.jsx` — 챗봇 상태로 감쌈, 원하는 단계로 바로 들어가기
- `entry.jsx` — 주소로 찾기 탭, 최근 건물, 말로 할래요, 진행 화면, 코드 탭 권유

- `steps.jsx` — 회수선 자석, (i) 물어보기, 헤맬 때 권유, 기저선 제목, 정산 AI 설명 접기+4초, 특약(공실·승계, 확인 3개 후 복사, AI 초안 표시)
- `ui.jsx` — (i) 안 물어보기 줄, 시트 머리 자리, 3칸 탭, 점 세 개 로딩, 아이콘(mic·up·trash·copy)
- `useSavingShare.js` — 관점(viewer), AI 특약 표시, 회수선 값 그대로 두기
- `client.js` — 저장본에 `/api/assist` 등 추가 · 화면이 `/app/` 이면 포트와 상관없이 같은 서버로
- `hooks.js` — 다크 기본 테마
- `styles.css` · `index.html` — 초록·다크 토큰, 새 부품 모양
- `vite.config.js` — 개발 프록시 주소를 `SS_API` 로 바꿀 수 있게(기본 8000 그대로)

## 9. 답 문구 가이드 (백엔드 템플릿도 이 말투로)

사용자 피드백: "챗봇이 너무 불친절해" — 못 알아들으면 같은 말만 되풀이하고, 주소를 말했는데 엉뚱한 합의 답(말하지도 않은 공사비 5천만·8년)이 나왔다.

원칙
- 짧게, 공감 먼저, 다음에 할 일까지. 한 답에 두세 문장.
- **같은 실패를 두 번 되풀이하지 않는다.** 두 번째에는 말을 바꾸고 다른 길(시연 건물, 건물 이름)을 준다.
- **사용자가 말하지 않은 숫자를 지어내지 않는다.** 공사비·기간이 없으면 묻는다.
- 못 찾은 이유를 말한다(우편번호라서, 데이터가 공개 안 된 건물이라서, 주택이라서).
- 칩은 다음 행동이다. 사용자 본인 정보가 필요한 칩은 보내지 말고 입력창에 넣어 준다(`{ "label", "fill" }`).

경우별 문구 (목업 `src/core/mockAssist.js` 에 그대로 들어 있음)
- 주소를 모를 때 ("내 집 주소를 모르겠어"): 괜찮아요. 주소를 몰라도 건물 이름이나 동네만 알면 찾을 수 있어요. 예를 들어 ‘역삼동 상가’나 ‘블룸비스타 호텔’처럼 말해 주세요. → [건물 이름으로 찾을게요(입력)] [시연 건물로 둘러볼게요]
- 우편번호 ("17085"): 17085는 우편번호 같아요. 우편번호로는 건물을 찾을 수 없어서, 도로명 주소(예: ○○로 12)나 건물 이름을 알려 주세요.
- 주소는 알겠는데 데이터 없음 (unregistered): 명지로 116번길 28-14는 아직 에너지 데이터가 없는 건물이에요. 공공데이터가 공개된 건물만 볼 수 있거든요. → [시연 건물로 둘러볼게요] [다른 주소로 찾을게요(입력)]
- 주택 (residential): 아파트·주택은 공공 에너지데이터 제공 대상이 아니라서 찾을 수 없어요. 상가나 사무실 건물이라면 주소를 알려 주세요.
- 찾음 (matched): 찾았어요. 이 건물이 맞나요? · 가상 데이터면 "다만 이 건물은 시연을 위해 만든 가상 데이터예요."를 붙인다
- 합의인데 조건 없음 ("합의 도와줘"): 좋아요, 같이 정해 봐요. 공사비가 얼마인지, 몇 년 안에 돌려받고 싶은지 알려 주세요. → [공사비 5천만, 8년] [조건 직접 쓸게요(입력)]

## 10. 알아서 채우기 · 서버 참고 구현 (`backend/assist.py`)

사용자 피드백: "내가 전부 다 알려주면 챗봇 쓰는 이유가 없지. 단순하게 넣어도 알아서 채워 넣든가 되물어보든가 해야지"

- 진짜 대화 입구를 백엔드 복사본에 만들었다: `backend/assist.py` + `main.py` 끝 두 줄 (`/api/assist` · `/api/mediate` · `/api/resolve` · `/api/analyze`)
  - 의도: `backend/saving_ai/` (자체 C++ 모델). 숫자: 요구서 3-1·3-3 공식 — 요구서 예시 값과 1원까지 같다 (65%·80%, 7.6/9.7/6.2/7.9년, 월 294,581원, 대안 30년·95,949,354원, 9,927/1,613/8,314 kWh)
- **채우는 순서**: 이번 말 → 직전 대화(`context.last` = 서버가 준 `state`) → 지금 화면 값(공사비·기간·열린 건물) → 이 건물 데이터
  - "합의 도와줘" → 화면의 공사비·기간으로 바로 계산 · "8년이면?" → 기간만 바꿔 다시 · "1억" → 공사비만 바꿔 다시
  - "가스" → 가장 크게 튄 달로 분석 · "8월" → 가장 최근 8월 · "작년 여름" → 그 여름 중 가장 많이 변한 달
  - 건물을 아직 안 골랐으면 시연 건물로 계산하고 그렇다고 알린다 → [이 조건으로 보기]를 누르면 그 건물을 열고 들어간다
  - "주소 몰라" · 우편번호 → 볼 수 있는 건물 목록을 바로 보여주고 누르게 한다
- **채운 것은 문장이 아니라 답 위 작은 한 줄**(`filled`): "✓ 공사비 5,000만 원 · 10년으로 계산했어요" — 바꾸기는 칩 [기간 바꿔 볼래요] [공사비 바꿔 볼래요]
- 채울 곳이 정말 없을 때만 **한 번에 하나** 묻는다: "5천" → "5천만 원 말씀이신가요?" [네, 5천만 원이에요] / 공사비가 없으면 "공사비가 얼마예요?" [5천만] [1억] [직접 쓸게요]
- 응답에 더한 것 (요구서 3-4 형식 + 선택 필드): `state`(다음 요청의 context.last 로 그대로) · `filled` · `building`(시연 건물로 계산했을 때) · `data.pick`("안전하게"면 안전 카드 먼저)
- 시연 주소: `http://<IP>:8130/app/` (목업 아님 · 진짜 AI). `?mock=1` 목업은 백엔드가 없을 때만 — 목업은 채우기를 하지 않는다
